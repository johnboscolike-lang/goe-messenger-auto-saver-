# Assets 폴더

이 폴더는 GOE Messenger Auto Saver에서 사용하는 정적 리소스 파일들을 포함합니다.

## 폴더 구조

```
assets/
├── images/         # UI 자동화를 위한 이미지 파일
│   └── README.md   # 필요한 이미지 목록 및 설명
└── README.md       # 이 파일
```

## 용도

### images/
pyautogui 라이브러리의 이미지 인식 기능에 사용되는 UI 요소 스크린샷입니다.
pywinauto 기반의 컨트롤 자동화가 실패할 경우 폴백(fallback) 방식으로 사용됩니다.

## 주의사항

1. **GOE메신저 업데이트 시**: UI가 변경되면 이미지 파일을 다시 캡처해야 합니다.
2. **해상도 의존성**: 이미지는 특정 해상도에서 캡처되어야 하며, 다른 해상도에서는 인식이 실패할 수 있습니다.
3. **DPI 설정**: Windows 디스플레이 배율 설정(100%, 125%, 150% 등)에 따라 이미지가 달라질 수 있습니다.

## 이미지 캡처 가이드

1. GOE메신저를 실행합니다.
2. Windows 캡처 도구(Win+Shift+S) 또는 스크린샷 프로그램을 사용합니다.
3. 버튼/아이콘만 정확히 선택하여 캡처합니다.
4. PNG 형식으로 저장합니다.
5. 여백을 최소화하고, 버튼의 경계가 명확하게 보이도록 합니다.
