## 이미지 캡처 방법

### 1. 준비
- GOE메신저(경기교육통합메신저)를 실행합니다.
- 화면 배율을 100%로 설정합니다 (Windows 설정 > 디스플레이 > 배율).

### 2. 캡처
```
1. 캡처할 UI 요소가 보이는 화면으로 이동합니다.
2. Windows + Shift + S 키를 누릅니다.
3. "사각형 캡처"를 선택합니다.
4. 버튼/아이콘 영역만 정확히 드래그하여 선택합니다.
5. 클립보드에 복사된 이미지를 이 폴더에 저장합니다.
```

### 3. 저장 규칙
- 파일 형식: PNG (투명 배경 권장)
- 파일명: 위 표의 파일명을 그대로 사용
- 크기: 원본 크기 유지 (확대/축소 금지)

## 캡처 시 주의사항

1. **정확한 영역 선택**
   - 버튼 테두리가 모두 포함되어야 합니다.
   - 불필요한 여백은 최소화합니다.
   - 주변 UI 요소가 포함되지 않도록 합니다.

2. **상태 주의**
   - 버튼은 기본 상태(hover/pressed 아님)에서 캡처합니다.
   - 아이콘은 활성화된 상태에서 캡처합니다.

3. **해상도 일관성**
   - 모든 이미지는 동일한 해상도/배율에서 캡처합니다.
   - 다른 PC에서 사용 시 이미지를 다시 캡처해야 할 수 있습니다.

## 이미지 테스트

캡처한 이미지가 제대로 인식되는지 테스트하려면:

```python
import pyautogui

# 이미지 인식 테스트
location = pyautogui.locateOnScreen('assets/images/btn_download.png', confidence=0.8)
if location:
    print(f"이미지 발견: {location}")
else:
    print("이미지를 찾을 수 없습니다. 다시 캡처하세요.")
```

## 트러블슈팅

### 이미지를 찾을 수 없는 경우
1. GOE메신저 버전이 업데이트되었는지 확인
2. 화면 해상도/배율 설정 확인
3. confidence 값을 0.7~0.9 사이로 조절
4. 이미지를 다시 캡처

### 잘못된 위치를 클릭하는 경우
1. 이미지에 고유한 특징이 충분한지 확인
2. 더 넓은 영역을 포함하여 다시 캡처
3. 비슷한 UI 요소가 화면에 여러 개 있는지 확인
